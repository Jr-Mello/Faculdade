P2P Mesh Vision System

Tese de Arquitetura: Barramento Analógico e Consenso Multimodal
PROJETO AVM: ARQUITETURA DE VISÃO MULTIMODAL DISTRIBUÍDA O AVM-Project-2026 rompe com o processamento centralizado de imagem ao implementar uma Rede Bridge P2P baseada em WebSockets. Utilizando classes Java Nativo em dispositivos de borda (Edge Computing) para análise matemática pesada e JavaScript para renderização de consenso, o sistema garante latência ultrabaixa e precisão cirúrgica através de um Barramento Analógico de Luz compartilhado entre nós especialistas.
