Projeto Integrador: Sistema de Ensino Offline

Engenharia de Software - Unopar | Aluno: Recuperando APAC Porto Alegre

🚀 Visão Geral

Desenvolvimento de um ecossistema educacional híbrido voltado para a alfabetização em ambientes com restrição de conectividade (metodologia offline). O sistema utiliza inteligência artificial para a geração dinâmica de conteúdo pedagógico.

🛠 Arquitetura Técnica

Java Android Nativo JavaScript (Front-end) JSON Persistence Edge Computing IA Generativa

Núcleo Servidor: Desenvolvido em Java Nativo para Android, atuando como o host central da rede local.

Comunicação: Interface Web servida via protocolo http://[IP_DO_SERVIDOR], garantindo acesso multiplataforma via navegador.

Dados: Persistência baseada em arquivos JSON e cache local, otimizando o fluxo de dados sem dependência de SQL externo.

🧩 Módulos do Ecossistema

  • Módulo Alfabetização: Criação de roteiros de aula automatizados via IA.
  • Gestão de Biblioteca: Controle de acervo e empréstimos integrado ao núcleo.
  • Sincronização Híbrida: Atualização de progresso via cache quando houver rede disponível.

🌍 Impacto Social (APAC Porto Alegre)

O projeto visa democratizar o acesso ao ensino básico dentro do sistema prisional, permitindo que a tecnologia de ponta (IA) funcione em hardware acessível (tablets/smartphones) sem a necessidade de infraestrutura complexa de internet.
