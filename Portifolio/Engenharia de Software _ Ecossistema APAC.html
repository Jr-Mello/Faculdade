Back-end Nativo

Servidor Java rodando diretamente no Android via WS, gerenciando sockets locais.

IA Pedagógica

Geração de roteiros de alfabetização adaptativos baseados em fonemas e JSON.

Zero Internet

Comunicação 100% via rede local IP, ideal para restrições de segurança na APAC.

Fluxo de Engenharia

Processo de Alfabetização

  • 1
    Entrada de Dados: O instrutor define um tema gerador.
  • 2
    Motor IA: O algoritmo gera exercícios fonéticos estruturados em JSON.
  • 3
    Servidor Java: O núcleo Android serve os dados via porta 8080 para a rede local.
