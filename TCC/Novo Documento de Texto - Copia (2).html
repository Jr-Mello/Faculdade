📡 Sensores de Entrada (I/O)

IA Preditiva SCT-013 (Corrente):

Análise de consumo e detecção de picos irregulares em motores.

Filtro de Ruído SW-420 (Vibração):

IA identifica padrões de trepidação fora do normal (Manutenção).

Análise de Tendência LM35 (Temperatura):

Monitoramento térmico com alertas via rede P2P.

🛠️ Lógica de Processamento

O fluxo do dado seguirá o seguinte caminho técnico:

  1. Aquisição: O sinal analógico entra pelo hardware de interface.
  2. Normalização: O software no tablet trata o sinal bruto (Remoção de ruído).
  3. Inferência: O modelo [TensorFlow Lite] classifica o estado do sistema.
  4. Sincronização: O resultado é enviado via P2P para o 17º dispositivo (Backup).
Tese Central: A inteligência não está no sensor, mas na capacidade do software móvel de interpretar dados ruidosos e tomar decisões sem um servidor central.
